# Connect Project to GitHub

## Goal
Enable two-way GitHub sync for the Avangarda salon website project.

## What to do
GitHub repository connection is performed inside the Lovable editor UI (not via code). The steps are:

1. Open the project in the Lovable editor.
2. Click the Plus (+) menu in the chat input → GitHub → Connect project.
3. Authorize the Lovable GitHub App.
4. Select the GitHub account/organization where the repository should be created.
5. Click Create Repository to push the current project code.

After this, changes made in Lovable will automatically push to GitHub, and changes pushed to GitHub will sync back into Lovable.

## Notes
- No project source files need to be changed to set up the connection.
- If the user wants, I can afterwards clean up the README or add metadata files before the first commit is visible on GitHub.
