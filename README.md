# Avangarda Beauty Hub

Create a modern, elegant, and welcoming single-page website for Salon Fryzjerski "Avangarda", a woman-owned hair salon located at Cedrowa 1b, 59-300 Lubin, Poland.

Business vibe: A highly trusted salon with a 4.9★ rating (32 reviews), built around stylist Ania, praised for precision, passion, and genuine care — clients specifically call her their favorite hairdresser and mention years of loyalty. Services include coloring, balayage, hydrating/nourishing treatments, and precision cuts (for both women and men), all done with professional cosmetics and careful, hygienic practices in a warm, friendly atmosphere. The salon is woman-owned and LGBTQ+ friendly — reflect both authentically and naturally in tone rather than as badges. Aesthetic: elegant, soft, and modern — a refined feminine touch without being overly delicate. Color palette: soft blush pink, warm beige/cream, and matte black or deep plum accents for sophistication. Typography: an elegant serif or refined script for headings, paired with a clean, modern sans-serif body.

Sections to include:

Hero — salon name/logo treatment, elegant tagline (e.g., "Where Every Client Leaves Smiling"), current hours, prominent "Book Online" CTA.

About — warm brand story emphasizing the salon's professional standards, hygienic/careful approach, welcoming atmosphere, and the passion and skill of stylist Ania and the team.

Meet the Stylist — small feature section on Ania, highlighting her specialties (coloring, balayage, precision cuts, nourishing treatments) and the genuine care/passion clients consistently praise.

Services — grid/list layout for services (haircuts, coloring, balayage, hydrating treatments, styling) with placeholder pricing if not specified, each with a "Book Now" CTA.

Gallery — grid layout for salon atmosphere and styling work (placeholder space for available photos).

Reviews — testimonial cards highlighting the 4.9★ rating with real quotes about loyalty, precision, and warm service.

Hours & Location — full weekly hours table (Mon–Fri 09:00–17:00, Sat 09:00–14:00, closed Sun), embedded map placeholder, address, and phone number (693 873 780).

Footer — contact info, hours recap, copyright, small LGBTQ+-friendly icon/badge.

Style requirements:

Fully responsive, mobile-first design

Soft, elegant color palette (blush pink, cream, plum/black accents)

Sticky navigation bar: Home, Stylist, Services, Gallery, Reviews, Hours/Location

Refined typography with graceful visual hierarchy, romantic but professional feel

Smooth hover effects, soft rounded shapes, gentle scroll animations

Repeated, prominent "Book Now" CTAs throughout the page

Make it feel personal and trustworthy — a salon built on genuine relationships and real craftsmanship, where clients become regulars for years.

## Deploy to Netlify

This project is configured for static export to Netlify.

### Option A: Drag-and-drop (fastest)

1. Build the static export:
   ```sh
   bun run build:netlify
   ```
2. Open [Netlify Drop](https://app.netlify.com/drop) and drag the `dist/client` folder onto the page.
3. Netlify will publish the site and give you a public URL.

> Note: `dist/client` contains a prerendered `index.html`, hashed JS/CSS assets, original salon images, and `netlify.toml` redirects, so deep links work as a single-page app.

### Option B: Connect a Git repo to Netlify

1. Push this project to a GitHub/GitLab repository.
2. In Netlify → Add new site → Import an existing project, choose the repo.
3. Set build command to `bun run build:netlify` and publish directory to `dist/client`.
4. Important: this project depends on the private `@lovable.dev/vite-tanstack-config` package. Netlify must be able to install it. Either keep builds inside Lovable and use drag-and-drop, or configure the private registry credentials in Netlify environment variables.
